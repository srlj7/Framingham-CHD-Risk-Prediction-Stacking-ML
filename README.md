# Framingham-CHD-Risk-Prediction-Stacking-ML
An End-to-End Clinical Machine Learning Framework for 10-Year Coronary Heart Disease (CHD) Risk Prediction on the Framingham Heart Study using Clinical Feature Engineering, Hybrid SMOTE-ENN, Two-Stage Tuning () -> [], and Stacking Ensemble (98.87% Recall, 98.53% F1, 99.88% ROC-AUC).
